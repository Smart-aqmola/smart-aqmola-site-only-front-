# Фотографии сотрудников

Сохраняйте здесь подтверждённые фотографии сотрудников.
В `src/data/organizationStructure.ts` указывайте публичный путь
`/images/team/имя-файла.jpg` в поле `photo` сотрудника.

Элемент `members` содержит уникальный `id`, `name` и `position`
с переводами `RU`, `KZ`, `EN`, а также необязательный `photo`.
При отсутствии фотографии поле `photo` можно не указывать.
Карточки создаются автоматически из `members`.

Не определяйте имена, должности и подразделения по внешности на фотографиях.
