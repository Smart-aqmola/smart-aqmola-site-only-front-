# Smart Aqmola

Корпоративный сайт на React, Vite, TypeScript и CSS. Реализованы только Header, Navbar и Hero.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` проверяет TypeScript и собирает сайт. `npm run lint` проверяет код ESLint.

## Файлы

- `src/components/Header.tsx` — бренд, переключатель языка, поиск по названиям разделов.
- `src/components/Navbar.tsx` — навигация и раскрывающееся мобильное меню.
- `src/components/Hero.tsx` — баннер, текст, кнопки и декоративный сетевой визуал региона.
- `src/components/Layout.tsx` — шапка и основной контент, без отображения подвала.
- `src/pages/HomePage.tsx` — главная страница, содержащая Hero.
- `src/content.ts` — тексты RU/KZ/EN и адреса будущих разделов.
- `src/styles/` — общие стили, адаптивная структура, оформление Header и Hero.
- `src/assets/region-panorama.svg` — временная иллюстрация города, не фотография реального региона.

Переключение языка переводит текущий интерфейс и меняет язык HTML-документа.
Поиск фильтрует названия разделов; полнотекстового поиска нет.
Ссылки навигации и кнопок указывают на будущие страницы: их содержимое и маршрутизация пока не реализованы.
Контур в Hero декоративный, не точная географическая карта Акмолинской области.
Панораму и карту нужно заменить утверждёнными материалами.
